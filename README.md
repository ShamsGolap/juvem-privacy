# Juvem — politique de confidentialité

Politique publique en français pour **Juvem**, application de bien-être créée par **GolApp Studio**.

- Dépôt : https://github.com/ShamsGolap/juvem-privacy

- Application : dépôt privé `ShamsGolap/juvem` (`feature/juvem-v1`), `com.golappstudio.juvem`.

## Publication (activation manuelle GitHub Pages)

Dans le dépôt : **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.

Ce dépôt statique n'a aucun script et aucun workflow Actions ajouté. Tant que Pages n'est pas activé, l'URL prévue **n'est pas attestée** comme accessible.

## Principes et points de vigilance

- Information fondée sur le code observé en octobre 2026 : pas de compte, publicité, analytique ou serveur applicatif, coffre local chiffré AES-256-GCM, clé Android Keystore / iOS Keychain, notifications facultatives, liens externes `tel:` et web.
- Le site est statique (sans formulaire, analytics, script ni cookies applicatifs). GitHub peut néanmoins traiter des données techniques liées aux requêtes.
- Les candidatures au test et messages envoyés par mail sont **un traitement distinct** des données stockées localement.
- **Contrôles impératifs avant diffusion large :** revue juridique RGPD, identification complète de l'éditeur et mentions légales, dates de conservation applicables aux e-mails/support, audit final SDK/permissions/export/sauvegardes (notamment iOS), exactitude du texte face à l'APK publié.
- Ne pas décrire Juvem comme application médicalement validée ou susceptible de diagnostiquer une personne.
- Toute mise à jour de l'application modifiant les pratiques de traitement nécessite une mise à jour de cette politique et de la date affichée.

## Sécurité

Signaler une question de protection des données à `golappstudio.support@gmail.com` sans transmettre de journal personnel ou de détails médicaux inutiles.

Ce site peut servir d'URL de politique de confidentialité dans Google Play Console **une fois Pages publié et les contrôles ci-dessus effectués**.
